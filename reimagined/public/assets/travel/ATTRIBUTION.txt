Modifications: removed Antarctica and the aggregate United Kingdom geometry,
inserted the four constituent UK country boundaries, normalized UK polygon winding
for spherical rendering, rounded coordinates to four decimal places, and reduced properties.
The source geometry is bundled locally so the globe needs no map API key or external runtime service.
